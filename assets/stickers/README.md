# SCARFACE Radio Sticker Assets

Generated asset sheet for rebuilding the radio UI with real bitmap decals instead of simple GDI line art.

Files:
- `scarface-radio-sticker-sheet.png`: original generated sticker sheet on green chroma-key background.
- `scarface-radio-sticker-sheet-alpha.png`: transparent PNG after chroma-key removal.
- `scarface-radio-atlas.json`: approximate sprite crop boxes for each decal.

Prompt used:
