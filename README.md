# 🎙️ Scarface Radio

A radio application built in Assembly language, featuring a user interface for audio playback.

## 📁 Project Structure

- **radio_plus.S** - Main radio player program
- **SOLO_01 to SOLO_09** - Additional modules and features
- **assets/** - UI and resource files

## 🛠️ Technologies

- **Language:** Assembly (ASM)

## 📖 Overview

This project implements a radio playback window/interface using Assembly, handling audio controls and user interaction at the system level.
